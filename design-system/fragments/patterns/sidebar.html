In light mode theme-overrides.css replaces each white-alpha wash with an ink equivalent; a hardcoded rgba(255,255,255,…) in new sidebar CSS will be invisible on white.
Brand-as-text fails contrast in light mode. The credits Top up link uses #dfff00 as a foreground colour: 1.14:1 on white and 1.07:1 on the light --background, against a 4.5:1 AA floor for body text.
