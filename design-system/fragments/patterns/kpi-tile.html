Brand-as-text fails contrast in light mode. The credits and velocity icon tints uses #dfff00 as a foreground colour: 1.14:1 on white and 1.07:1 on the light --background, against a 4.5:1 AA floor for body text. Reproduced faithfully rather than corrected — it is a real bug in the app. Note that no point on the current ramp fixes it: --brand-active #c8e600 still only reaches 1.42:1. Light mode needs either a dark olive token (around #6b7a00, which measures 4.76:1) or the treatment the primary button already uses — brand as a background with black text, which measures 18.4:1.
