Hover on every filled variant lifts by 1px (hover:-translate-y-px). The xs, icon-xs, icon-sm and icon-lg sizes are VesperWise additions and are not in upstream shadcn.
The default variant's glow shadow hardcodes rgba(223,255,0,0.7) instead of reading --brand-glow (components/ui/button.tsx:12). Changing the brand token alone will not update it.
The link variant uses --brand-ink, not --brand. #dfff00 as a foreground colour measures 1.14:1 on white. --brand-ink stays #dfff00 in dark mode and drops to a dark olive (--brand-ink) in light, where its worst case across every light surface is 5.05:1. Rule of thumb: --brand fills, borders and glows; --brand-ink text and icons.
The ! on text-brand-ink! is load-bearing. globals.css:568-569 declares a and button { color: inherit } outside any @layer, and unlayered CSS beats layered CSS whatever the specificity — so a plain colour utility never reaches an anchor or a button in this app. Verified by measurement, not assumed.
