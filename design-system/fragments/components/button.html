Hover on every filled variant lifts by 1px (hover:-translate-y-px). The xs, icon-xs, icon-sm and icon-lg sizes are VesperWise additions and are not in upstream shadcn.
The default variant's glow shadow hardcodes rgba(223,255,0,0.7) instead of reading --brand-glow (components/ui/button.tsx:12). Changing the brand token alone will not update it.
Brand-as-text fails contrast in light mode. The link variant uses #dfff00 as a foreground colour: 1.14:1 on white and 1.07:1 on the light --background, against a 4.5:1 AA floor for body text. Reproduced faithfully rather than corrected — it is a real bug in the app. Note that no point on the current ramp fixes it: --brand-active #c8e600 still only reaches 1.42:1. Light mode needs either a dark olive token (around #6b7a00, which measures 4.76:1) or the treatment the primary button already uses — brand as a background with black text, which measures 18.4:1.
